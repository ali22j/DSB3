# Age Estimation Using Deep Learning
## Project Overview

This project aims to predict a person's age from facial images using Deep Learning and Convolutional Neural Networks (CNN).

The model is trained using the UTKFace dataset to estimate age based on facial features.

## Objectives
Predict age from facial images.
Apply image preprocessing techniques.
Build and train a CNN model.
Evaluate model performance.
## Dataset

UTKFace Dataset

Contains facial images with age, gender, and race labels.

Images are resized to 128 × 128 pixels and normalized before training.

🛠️ Technologies
Python
TensorFlow & Keras
CNN
Pandas
Scikit-learn
🧠 Model Architecture

The CNN model includes:

3 Convolutional Layers.
Batch Normalization.
Max Pooling.
Dense Layer.
Dropout.
Regression Output Layer.
## Results
Best Validation MAE: 7.22 years
